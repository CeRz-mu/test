# かんたん帳簿

円建ての収入・支出を記録する、GitHub の動作確認用ミニアプリです。取引の登録・削除、日付順の履歴、収入・支出・残高の集計ができます。

## 起動

`index.html` をブラウザーで開きます。ブラウザーがローカルファイルへの保存を制限する場合は、このフォルダーで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。データは使用中のブラウザーに保存されます。テストには架空の取引を使ってください。

## GitHub で確認

このフォルダーの中身を `.github` ディレクトリも含めてリポジトリのルートに置きます。push や PR の作成で GitHub Actions の `Ledger checks` が動きます。手元で同じチェックを実行するには Node.js 24 を使います。

```sh
node --check app.js
node --test ledger.test.js
```

失敗したチェックを試す場合は、テスト用ブランチで `ledger.test.js` の残高の期待値を `-500` から `-501` に変えて push します。Actions のログで失敗内容を確認し、期待値を戻すと再び成功します。
